# 粵語口語練習 🗣️（香港粵語）

給台灣人（國語母語）**從零開始學香港口語粵語**的網頁 App，手機可以直接加到主畫面當 App 使用，也能離線複習。

👉 **立即使用：https://xiao-xiang-gu.github.io/hk-cantonese/**

---

## 📱 安裝到手機

不用下載任何 App，用瀏覽器打開上面的網址就能用。加到主畫面後，會出現橘色「粵」字圖示，打開就是全螢幕。

| 手機 | 步驟 |
|---|---|
| **iPhone** | 用 **Safari** 打開網址 → 點下方「分享」按鈕 → 選「**加入主畫面**」 |
| **Android** | 用 **Chrome** 打開網址 → 點右上角「⋮」→ 選「**安裝應用程式**」或「**加到主畫面**」 |

- **離線使用**：有網路時打開過一次，之後沒網路也能用（例如在港鐵上）。
- **自動更新**：課程更新後，下次有網路打開時就會更新成新版。
- **學習進度**：字卡的熟練程度只存在你自己的手機瀏覽器裡，不會上傳；清除瀏覽器資料會重置進度。

## ✨ 功能

| 功能 | 說明 |
|---|---|
| **課程** | 10 課生活情境，每句都有繁體字、粵拼、台灣國語翻譯和用法說明，可正常速度或 🐢 慢速播放 |
| **句型** | 20 個聽懂整句的關鍵：句尾語氣詞（呀、啦、喎、囉、㗎、咩、嘛、啩）、連接詞（因為、但係、咁、如果、定係…）、口語句型（先…再、緊、晒…），共 80 句例句 |
| **對話劇場** | 5 段原創短劇（家庭劇、職場劇、生活喜劇、日常、卡通），可整齣連續播放並標示目前台詞，也能隱藏粵拼和翻譯純練聽力 |
| **聲調** | 六個聲調示範（詩、史、試、時、市、事）＋**聲調對比聽辨**，專練國語母語者最容易混淆的組合 |
| **聽力測驗** | 聽發音，從四個選項選出正確意思；可選「詞句」或「整句」 |
| **跟讀** | 用麥克風唸出詞句或整句，語音辨識後打分數 |
| **字卡複習** | 看粵語想意思和唸法，答錯的卡會更常出現 |

## 🔊 發音小提醒

- 發音使用裝置內建的**粵語（zh-HK）語音**。iPhone 和大部分 Android 手機都有內建。
- **Windows 電腦**建議用 **Edge** 開啟；如果聽起來像國語，可到「設定 → 時間與語言 → 語音」新增「中文（香港）」語音。
- **跟讀功能**需要支援語音辨識的瀏覽器（Chrome、Edge、iPhone Safari），並允許使用麥克風、保持連網。
- 合成語音和真人發音仍有差距，聲調請以真人錄音（例如港劇、YouTube）為最終參考。

## ✅ 內容品質

- 以**香港人日常口語**為準，不是廣州話，也不是書面語。香港人實際會夾雜的英文（如 book、check in、OK）會照實保留並加註說明。
- 粵拼採用香港語言學學會的 [LSHK 粵拼方案](https://lshk.org/jyutping-scheme/)，用字參考 [粵典 words.hk](https://words.hk/)。
- 課文由 Claude、Codex、ChatGPT、Meta Muse 交叉撰寫與審稿。如果發現錯誤或更道地的說法，歡迎在 [Issues](https://github.com/Xiao-Xiang-Gu/hk-cantonese/issues) 提出。

## 🛠 專案結構

```
index.html            App 本體（介面與所有功能）
lessons.js            課程資料、聲調示範、聲調對比題
patterns.js           常用句型（語氣詞、連接詞、口語句型）
stories.js            對話劇場（原創短劇）
manifest.webmanifest  手機安裝設定
sw.js                 離線快取
icons/                App 圖示
tools/                呼叫 Codex 審稿的輔助腳本（Windows）
```

### 新增課程

在 `lessons.js` 的 `LESSONS` 陣列加入一個物件即可，格式如下：

```js
{
  id: "英文小寫-用連字號",
  title: "課名",
  goal: "這課學完能做到什麼",
  vocab: [
    { hanzi: "唔該", jyutping: "m4 goi1", mandarin: "麻煩你／謝謝", note: "選填：用法說明" }
  ],
  dialogue: [
    { speaker: "A", hanzi: "早晨！", jyutping: "zou2 san4!", mandarin: "早安！" }
  ],
  tips: ["文法小提示"]
}
```

發布新版時，記得把 `sw.js` 裡的 `CACHE` 版本號加 1（例如 `hk-cantonese-v2`），讓已安裝的手機清掉舊快取。

### 在電腦上預覽

```
python -m http.server 8000
```

然後用瀏覽器打開 http://localhost:8000 。
